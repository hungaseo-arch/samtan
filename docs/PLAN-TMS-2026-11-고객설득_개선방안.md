## 0. 결론

1. 지금 화면에 나오는 숫자로 고객을 설득하면 오히려 손해임. 수명 DB의 주행 KM이 실제보다 약 40% 짧게 나오고 있음 (마모 폐기 17본 평균 34,415 km, 실제 57,121 km — `WO-TMS-2026-11-LIFE-KM`)
   - 단가 IDR 13,000,000 기준 본당 CPK : 현재 화면 약 IDR 377.74/km, 수정 후 약 IDR 227.59/km
   - 즉 이 값을 고치는 것만으로도 고객에게 보여 줄 원가가 약 40% 낮아짐
2. 순서는 **① 숫자 신뢰 회복 → ② 고객용 월간 리포트 → ③ 비교 · 절감 분석 → ④ 다른 광산으로 확장**
3. 지금 사이트는 내부 관리 화면임(현장 감독 로그인). 고객이 보는 1쪽짜리 결과물(리포트)과 고객 전용 조회 권한이 없음 → 가장 큰 공백
4. 티맨의 엔지니어링 판단이 꼭 필요한 항목은 8개임(5장). 기준을 정하지 않고 화면부터 만들면 고객 앞에서 반박당함

## 1. 현황 진단 — 고객 설득 관점

| 구분 | 현재 상태 | 설득 자료로서 문제 |
|---|---|---|
| 수명 (km) | 수명 DB 평균 34,415 km (하한값 다수) | 실제보다 약 40% 짧음. 고객은 성능에 만족하는데 TMS 숫자만 나쁨 |
| 마모속도 | km/mm 표시 (예 3,690 km/mm) | 값은 좋지만 비교 기준(업계 · 경쟁제품)이 없어서 좋은지 나쁜지 판단할 수 없음 |
| 예상 수명 | 최소 트레드 0 mm 기준 외삽 | 수명 종료 기준이 「숄더 완전 마모」로 확정됨(LIFE-KM §1) → 지금 기준이면 예상 수명이 짧게 나옴 |
| CPK | CPK-G만 산출 (CPK-T · CPK-L은 파라미터 미확정) | 고객이 실제로 쓰는 돈(운송 · 장착 · 다운타임)이 빠져 있음 |
| 경쟁 비교 | NONTK 임시 시리얼, 단가 미확정 → CPK 산출 안 함 | 「Techking이 더 싸다」를 보여 줄 수 없음 |
| 관리 효과 | 공기압 준수율, 연료 · 수명 손실 추정(계수는 가정값) | 계수가 가정값이라 금액으로 주장하기 어려움 |
| 결과물 | 화면 + 탭별 엑셀 | 고객에게 줄 1쪽짜리 보고서가 없음, 3개 언어 고객 문구 없음 |
| 데이터 신뢰 | 결과 요약 카드에 「데이터 확인 필요」 배지 | 장점임. 고객 리포트에도 신뢰도 표기를 그대로 가져가야 함 |
| 미결 | PR #6 미머지, 마이그레이션 3건(M-12) prod 적용 대기, CH 847 KM 오기, CH 832 · 835 KM 중복 의심, 0 mm 의미 확인 | 리포트를 만들기 전에 정리해야 함 |

## 2. 개선 방향 — 4단계

### 단계 1. 숫자 신뢰 회복 (2026-11 2~3주차, 선행 필수)

| # | 과제 | 근거 | 완료 기준 |
|---|---|---|---|
| 1-1 | PR #6 머지 + M-12 마이그레이션 3건 prod 적용 | decisions M-8~M-12 | 쎄오님 승인 후 적용, 가중 CPK 562.43 확인 |
| 1-2 | `WO-TMS-2026-11-LIFE-KM` 구현 (최초 장착분 시작점 · 거리와 마모 점열 분리 · 숄더 기준 예상 수명 · 3 mm 명칭 「권장 교체」) | 티맨 작성 WO | 17본 수용 표 ±1 km 일치 |
| 1-3 | 현장 확인 4건 : CH 847 07-12 KM, CH 832 · 835 KM 중복 · HM 이중 누적, 0 mm 의미, NONTK 실시리얼 | 미결 목록 | 원본 점검표 확인 후 소프트 삭제 + 재입력 |

- 이 단계가 끝나기 전에는 고객에게 수치를 보내지 않음

### 단계 2. 고객용 월간 리포트 (2026-11 4주차 ~ 12월)

**2-1 「월간 타이어 성능 리포트」 1쪽 (인쇄 · PDF, 한국어 · 인니어 · 영어)**

| 블록 | 내용 | 출처 화면 |
|---|---|---|
| 핵심 성과 4개 | 평균 수명 km(마모 폐기 기준) · 마모속도 km/mm · 예상 수명(숄더 기준) · 본당 CPK | 수명 DB · 마모 분석 · 원가 분석 |
| 목표 대비 | 목표 수명(`target_life_km`) 달성 본수 · 달성률 | 경제성 요약 |
| 관리 상태 | 공기압 준수율, 편마모 차량, 권장 교체 임박 본수 | 공기압 · 배치도 |
| 탈착 사유 | 제품 · 정비 · 운전 · 노면 귀속 비율 | 원가 분석 ③ |
| 권고 3건 | 이번 달 조치 (예 : 공기압 보정, 로테이션, 과적 차량) | 신규 |
| 신뢰도 표기 | 표본 본수, 하한값 본수, 데이터 확인 필요 항목 | 결과 요약 카드 |

- 화면 하나에서 기간을 고르고 인쇄 → PDF. 숫자는 기존 뷰와 같은 함수로 계산 (리포트 전용 계산식을 따로 두지 않음)
- 발송은 승인 게이트임 (삼탄 · Techking 현장 담당 앞 발송은 쎄오님 승인 후)

**2-2 고객 조회 계정**

- 지금 권한은 admin · inspector · viewer 3단계임 → 고객용 `customer` 역할 추가 검토
- 고객 화면에서는 입력 · 관리 · 원가 파라미터 · `finance` 스키마를 숨김 (decisions D-2 구매원가 격리 유지)
- 도메인 분리(COM-01 · 02 보류 건)와 같이 결정

### 단계 3. 설득 분석 기능 (2026-12 ~ 2027-1Q)

| # | 기능 | 고객에게 주는 메시지 | 선행 조건 |
|---|---|---|---|
| 3-1 | 경쟁제품 비교 : 같은 차량 · 같은 포지션 쌍 비교(수명 · km/mm · CPK), 표본 수 · 편차 표기 | 「같은 조건에서 Techking이 km당 얼마 싸다」 | NONTK 실시리얼 · 브랜드 · 단가 확보 |
| 3-2 | 절감 시뮬레이터 : 차량 수 · 월 주행 · 현행 수명 · 단가 입력 → 연간 타이어비 · 교체 횟수 · 정지 시간 차이 | 영업 상담에서 바로 쓰는 금액 | CPK-T 부대비용 확정(곳간) |
| 3-3 | 관리 효과 정량화 : 공기압 준수 구간과 미준수 구간의 마모속도 비교 → 수명 손실 · 연료 손실 금액 | 「TMS 관리 서비스로 이만큼 아꼈다」 | 민감도 계수 검증(티맨) |
| 3-4 | 로테이션 권고 : 조향축 숄더 마모 · 구동축 센터 마모 패턴으로 교환 시점 · 위치 제시, 기대 연장 km | 수명을 더 늘리는 구체 조치 | 로테이션 기준(티맨) |
| 3-5 | 하중 · TKPH 경고 : 과적 차량 · 고속 구간의 수명 영향 | 수명 저하가 제품 탓이 아님을 보여 줌 | TKPH 산정 조건(티맨) |
| 3-6 | 재생 · 케이싱 시나리오 활성화 (CPK-L) | 생애 원가로 한 번 더 절감 | 재생비 · 재생 후 수명 · 회수가치 |

### 단계 4. 확장 (2027-1Q, 사업계획 Dx·Ax 연계)

- 다고객 구조(고객별 데이터 분리) · 발릭빠빤 현장 입력 권한 · 고객 리포트 자동 생성
- 삼탄 결과를 익명화한 사례집 1부 → 신규 광산 영업 자료
- 2027.05.01 발릭빠빤 오픈과 함께 삼탄 운영을 지점 관할로 이관하고, 신규 광산 1곳 시범

## 3. 고객 보고 서술에서 먼저 정할 것

| # | 쟁점 | 현재 | 정할 것 |
|---|---|---|---|
| 1 | 중앙 마모(CW) 귀속 | DB는 MAINTENANCE(정비, 확정). 실차보고서는 중앙 마모 52.2%를 Techking 클레임 근거로 사용 | 고객 리포트에서 「과공기압 관리 문제」로 쓸지, 서술 방식을 하나로 정함 (분류 자체는 재논의하지 않음) |
| 2 | CPK 대표값 | 가중평균(Σ비용 ÷ Σ주행)으로 결정(M-10) | 고객 리포트도 가중평균 하나만 씀 |
| 3 | 단가 공개 | IDR 13,000,000(판매가)은 고객이 산 가격 | 리포트에 판매가를 쓰는 것은 문제없음. 당사 매입원가는 절대 노출하지 않음 |
| 4 | 하한값 표기 | 「(하한값)」 표시 | 고객용 문구는 「최소 ○○ km 이상」으로 바꿔 장점으로 표현 |
